# Jobtracker

Jobtracker is a fullstack job application tracking app built with React, TypeScript, ASP.NET Core and PostgreSQL.

## Tech Stack

- React + TypeScript + Vite
- ASP.NET Core Web API
- PostgreSQL
- EF Core
- Clerk Auth
- Vercel / Railway / Neon

## Project Structure

- `web/` — React web application
- `api/` — ASP.NET Core Web API
- `db/` — database notes, seed data and schema docs
- `docs/` — project documentation
- `mobile/` — future Expo mobile app
